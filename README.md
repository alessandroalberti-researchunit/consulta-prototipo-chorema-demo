# Consulta Roma, cruscotto dimostrativo con contesto Chorema

Prototipo dimostrativo del cruscotto Turismo per il pilota di Piazza Risorgimento. I flussi sono dati simulati. La vista «Contesto territoriale» usa dati Chorema (ISTAT, Corine Land Cover, OvertureMaps, ERA5, CAMS) riaggregati su griglia H3, che descrivono il contesto dell'area e non i flussi.

Aprire `index.html` tramite un server statico (`python -m http.server`) oppure dal sito pubblicato con GitHub Pages. Vista Contesto: `#contesto`.
