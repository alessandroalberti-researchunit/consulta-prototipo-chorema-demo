# Consulta Roma, cruscotto dimostrativo

Prototipo dimostrativo del cruscotto Turismo per il pilota di Piazza Risorgimento. I flussi sono dati simulati. La vista «Contesto territoriale» mostra dati di contesto dell'area riaggregati su griglia H3: mappa interattiva con tre indicatori per cella, card a tema e confronto tra rioni.

Aprire `index.html` tramite un server statico (`python -m http.server`) oppure dal sito pubblicato con GitHub Pages. Vista Contesto: `#contesto`.
